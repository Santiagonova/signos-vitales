# signos-vitalesProyecto de C++ para practicar Git y GitHub Desktop mediante ramas y pull requests.

## Funciones que se integrarán
- `fahrenheitACelsius(double f)`: convierte grados Fahrenheit a Celsius.
- `clasificarFrecuencia(int lpm)`: clasifica la frecuencia cardiaca como bradicardia, normal o taquicardia.

## Compilar
Con un compilador g++ instalado:

```bash
g++ signos.cpp -o signos
```

En Windows, ejecutar después:

```bash
signos.exe
```

## Nota
Este proyecto usa datos de prueba. No introducir datos reales de pacientes.
